# Цель проекта
симулировать данные, похожие на данные в закрытом контуре целевого заказчика, - для отработки методов их обработки в открытом контуре разработки (и переиспользования подходов)
# Что делает
на основе yaml-описания предметной области генерит короткие технические комментарии службы техподдержки по обращениям абонентов в техподдержку - стандартное поле тикета техподдержки телеком оператора
# Как планируется использовать
обычные трансформеры и эмбеддинги общеязыковых моделей (обученные и доступные в интернете) дают плохую метрику для кластеризации по косинусной схожести текстовых комментариев техподдержки - эмпирический результат.  Поэтому я хочу обучать свой эмбеддинг - далее буду подбирать слои модели и писать цикл обучения по эпохам на корпусе, который сгенерит данный генератор
# Структура папок
* `notebooks` - запускающие блокноты
* `src` - модули кода на питоне (конфигурационные переменные, функции и классы)
* `dictionaries`, `topology`, `language` - yaml-дефиниции параметров генерации текстов из предметной области
